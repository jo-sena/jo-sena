# Névoa IA

Este repositório contém uma implementação simples da página inicial da Névoa IA utilizando Web Components e PWA.

Abra `index.html` em seu navegador para visualizar a página. Os estilos principais estão em `style.css` e a lógica de componentes em `components.js`.

Para registrar o service worker e ativar a versão PWA, sirva o diretório via HTTP.
